# 🎓 Student Performance Prediction

## 📌 Project Overview
This project predicts student performance based on:
- Study hours
- Attendance
- Assignments submitted

## ⚙️ Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## 📊 Features
- Data preprocessing
- Linear Regression model
- Evaluation using MAE and R² score
- Data visualization:
  - Study Hours vs Score
  - Attendance vs Score
  - Assignments vs Score
  - Actual vs Predicted
  - Residual Plot
  - Correlation Heatmap

## 📈 Results
- Model predicts student scores with reasonable accuracy
- Residual analysis shows minimal bias
- Study hours and attendance have strong impact

## 🚀 How to Run
1. Open the notebook in Google Colab
2. Upload dataset
3. Run all cells
